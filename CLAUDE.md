# Instructions for agents working in this repository

Before working, read:

- `SKILLS.md`: how the tool works and how to extend it.
- `PLAN.md`: goals, decisions, what is done and what is next.
- `STYLE_GUIDE.md`: how everything must look.

**Keep the docs up to date. With every change, in the same commit:**

1. Update `SKILLS.md` if you add, remove or rename a feature, file, asset,
   setting, rule, debug hook or workflow.
2. Update `PLAN.md`: move finished work to "Done", add new next steps,
   known issues and decisions the owner made.
3. Update `STYLE_GUIDE.md` for anything that changes how things look, and
   `README.md` for user-facing behaviour.

Before committing: `npm run build` must pass, and check the change visually
(see "Testing and checking" in SKILLS.md).

The owner writes comics in Japanese: when asked for help with Japanese
(signs, text), include the hiragana reading, an English translation and
grammar notes.
